# New Gym

App personal de entrenamiento: rutina por slots con alternativas A/B/C, reemplazo guiado cuando una máquina está ocupada, guía de esfuerzo (qué tan cerca del fallo), conteo semanal de series por músculo y día 4 de rescate.

- `prototipo/index.html`: prototipo interactivo (HTML/JS sin dependencias). Ábrelo en el navegador.

Stack previsto: HTML/JS como PWA, datos en Google Sheets vía Apps Script, publicada en Cloudflare Pages.
